# Play Store Assets Directory

This directory contains official Google Play publication assets generated for **CalorieSnap**, published by **ViveScript Solutions LLC**.

## Folder Structure

```
/play_store_assets/
├── app-icon/
│   ├── app-icon-512x512.png         # 512x512 32-bit PNG Google Play Icon
│   ├── app-icon-foreground.png     # Adaptive foreground layer
│   └── app-icon-background.png     # Adaptive solid background layer (#10B981)
│
├── feature-graphic/
│   └── feature-graphic-1024x500.png # 1024x500 PNG Google Play Feature Graphic
│
├── phone/
│   ├── phone-01-calculator-hero.png    # 1080x2400 Phone Screenshot 1
│   ├── phone-02-bangla-foods.png       # 1080x2400 Phone Screenshot 2
│   ├── phone-03-portion-adjuster.png   # 1080x2400 Phone Screenshot 3
│   └── phone-04-social-share.png       # 1080x2400 Phone Screenshot 4
│
└── tablet/
    ├── tablet-01-landscape.png         # 1920x1200 Tablet Landscape
    └── tablet-02-portrait.png          # 1200x1920 Tablet Portrait
```

## Temporary Directory Note

As specified in Section 35 and 36 of the development instructions, this directory and `/production_build` can be cleanly removed prior to publishing the source code repository publicly on GitHub.
